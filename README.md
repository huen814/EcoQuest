# EcoQuest: Guardians of the Green City

A 2D waste-sorting game built with Java, JavaFX and FXGL. Walk around a tile-based city, pick up litter, sort it into the right bins, row a boat to clean the river, and plant saplings to restore the area.

> **Status:** Finals group project by group *codevibers* for Object Oriented Programming. Work in progress.

## Requirements
- JDK 21
- Maven

## Run
```bash
mvn javafx:run
```
Optional: `python3 tools/gen_sprites.py` regenerates all the art. You only need this if you want to change the textures.

## Controls
| Key | Action |
|---|---|
| Arrows / WASD | Walk |
| E / Z / Enter | A button (pick up / drop / sort / plant) |
| Space | Empty bin |
| B | Boat |
| P / Esc | Pause (also the PAUSE button, top right) |
| X | Back in menus |
| M | Mute |

## Project Layout
- `model/`: pure Java game rules on a 15x10 tile grid (no JavaFX). `GameSession` holds the whole game state.
- `view/`: FXGL/JavaFX screens: `PlayScreen` (main gameplay), `MapView`, `Hud`, `DialogBox`, `MenuBox`, and the menus (`MainMenuScreen`, `LevelSelectScreen`, `ModesScreen`, `ShopScreen`, `HowToScreen`).
- `EcoQuestApp` + `InputState`: window setup, screen switching, keyboard input.
- `tools/gen_sprites.py`: generates every texture (player sheets, items, bins, tiles, backdrops). You can swap in hand-made PNGs with the same name and size.

## Optional: Pixel Font
Drop `PressStart2P.ttf` into `src/main/resources/assets/ui/fonts/` for a more retro look. Without it the game uses bold monospace.

## Testing and Development Status
- **Model layer:** compiled and fuzz-tested headlessly on all 15 levels/modes. A greedy bot clears level 1 with 3 stars.
- **View layer:** runs with FXGL 21.1 via `mvn javafx:run` / IntelliJ and has been playtested by the author. Controller/mouse input and further testing are still pending.
- **Not done:** gamepad/mouse support, balance tuning (movement is tile-based, so speeds and reach differ from the earlier Swing prototype), animated clouds/factory smoke, music.
